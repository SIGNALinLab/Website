# Signal Processing & AI Lab Website

This is a GitHub Pages-ready static website package for the Signal Processing & AI Lab.

## Included pages

- `index.html` — homepage
- `contact.html` — professional contact page with address, phone, email, office hours, contact form, and campus-style map panel
- `projects/index.html` — projects landing page
- `projects/gpo.html` — Graduate Project Opportunities page
- `projects/sdp.html` — Senior Design Projects page with project descriptions, graphical abstracts, and resource links

## Main features

- Professional academic lab design
- Projects dropdown with `GPO` and `SDP`
- Animated inner-page headers
- Responsive design for desktop, tablet, and mobile
- Custom SVG logo
- Static HTML/CSS/JS only, suitable for GitHub Pages

## How to publish on GitHub Pages

1. Unzip this package.
2. Open the folder `spai-lab-github-ready`.
3. Upload all files and folders inside it to your GitHub repository root.
4. In GitHub, go to **Settings → Pages**.
5. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. Save and wait for GitHub to deploy.

## What to customize

Search in the HTML files and replace:

- Lab name
- University and department name
- PI email and contact email
- Phone number
- Address and map/directions text
- Team members
- Publications
- News
- GPO/SDP project names, descriptions, and external links

The current external links are placeholders such as YouTube, GitHub, Google Scholar, and `mailto:` links.
